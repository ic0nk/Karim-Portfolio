UX Design Project

Picoo Custom Quiz Feature

Empowering teachers to create engaging, interactive outdoor learning experiences through customizable quiz content

Project Overview

Picoo is an innovative company that combines technology with outdoor games for children, creating screen-free interactive experiences that are used in elementary schools. This UX design project focuses on developing a custom quiz creation feature that allows teachers to create their own quiz content tailored to their curriculum needs.

Client:
Picoo
Target Users:
Primary school teachers
Platform:
Desktop (primary) with mobile companion
Timeline:
March - April 2025

Challenge & Solution

The Challenge

Currently, teachers using Picoo can only choose from pre-made questions provided by the company. They lack the ability to create custom questions that align with their specific curriculum or classroom needs. Additionally, the timer settings are fixed, which can be problematic for different playground sizes and student abilities.

Key issues identified through research:

  • Limited question customization options
  • Fixed timer settings that don't accommodate different needs
  • No desktop interface for efficient content creation
  • Lack of accessibility options for students with different abilities

Our Solution

We designed a comprehensive custom quiz creation feature that empowers teachers to create, manage, and deploy their own educational content through the Picoo system. The solution prioritizes desktop usage for content creation while maintaining mobile compatibility for on-the-go adjustments.

Key solution components:

  • Intuitive desktop interface for quiz creation and management
  • Customizable timer settings for individual questions or entire quizzes
  • Mobile companion app for quick adjustments and deployment
  • Accessibility options for students with different learning needs
  • Seamless integration with existing Picoo devices

Key Features

Teacher Dashboard

The dashboard provides a comprehensive overview of all created quizzes with intuitive management tools. Teachers can quickly access their quiz library, create new content, and monitor usage statistics.

Key Elements:

  • Quiz library with search and filter options
  • Quick-access buttons for common actions
  • Recent activity and usage statistics
  • Template library for faster quiz creation
  • System notifications and updates

Quiz Creator Interface

The quiz creator provides a user-friendly interface for building custom educational content. Teachers can create various question types, add media, and preview content as they build.

Key Elements:

  • Multiple question type options (multiple choice, true/false, open-ended)
  • Rich text editor with formatting options
  • Media upload capability for images
  • Real-time preview of questions
  • Drag-and-drop question reordering
  • Auto-save functionality to prevent data loss

Customizable Timer Settings

Addressing a key pain point identified in user research, the timer settings feature allows teachers to customize time limits based on playground size, student abilities, and question complexity.

Key Elements:

  • Global timer settings for the entire quiz
  • Individual question time adjustments
  • Preset options for different playground sizes
  • Accessibility mode with extended timers
  • Visual timer preview

Quiz Deployment

The deployment interface provides a seamless connection between the quiz creation platform and the physical Picoo devices, allowing teachers to easily transfer content to devices and monitor active sessions.

Key Elements:

  • Device discovery and connection management
  • Visual confirmation of successful transfers
  • Remote session control (start, pause, end)
  • Real-time status monitoring
  • Quick quiz selection from library

Mobile Companion View

While the desktop interface is optimized for content creation, the mobile companion provides essential functionality for on-the-go management and deployment of quizzes.

Key Elements:

  • Simplified quiz library access
  • Basic editing capabilities for existing quizzes
  • Device connection and quiz deployment
  • Session monitoring and control
  • Push notifications for quiz completion

User Flows

Creating a Custom Quiz

  1. Teacher logs into desktop dashboard
  2. Clicks "Create New Quiz" button
  3. Enters quiz title, subject, and grade level
  4. Adds questions one by one, setting type and content
  5. Customizes timer settings for each question or globally
  6. Previews the entire quiz
  7. Saves quiz to library
  8. Syncs quiz to Picoo devices when ready to use

Modifying Timer Settings

  1. Teacher selects existing quiz from library
  2. Clicks "Edit" button
  3. Navigates to timer settings section
  4. Adjusts global timer or individual question timers
  5. Saves changes
  6. Option to sync updated quiz to devices

Deploying Quiz to Devices

  1. Teacher selects quiz from library
  2. Clicks "Deploy to Devices" button
  3. Sees list of available Picoo devices
  4. Selects target devices
  5. Confirms deployment
  6. Receives confirmation when quiz is ready on devices
